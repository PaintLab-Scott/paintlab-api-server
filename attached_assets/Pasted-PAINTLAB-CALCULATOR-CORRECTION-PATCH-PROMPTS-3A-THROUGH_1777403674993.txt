8. COMMERCIAL / NON-MULTIFAMILY PRICING LOGIC
==================================================

Commercial pricing must be cadence-based using the selected tier.

Use this model:

selected zone PSSF per visit
× visits per year
÷ 12
× base rate

Implement or verify this logic:

function calculateCommercialPerVisitPSSF(inputs) {
  let total = 0;

  if (!inputs.areas || inputs.areas.length === 0) return 0;

  inputs.areas.forEach(area => {
    const qty = area.quantity || 0;
    const floors = area.floors || 1;
    const sqft = area.squareFeet || 0;
    const service = area.service || "touchup";

    const serviceMultiplier = SERVICE_MULTIPLIERS[service] || 0.35;

    if (qty > 0 && sqft > 0) {
      total += qty * floors * sqft * 3.5 * serviceMultiplier;
    }
  });

  return total;
}

function calculateCommercialMonthly(inputs, rate) {
  const perVisitPSSF = calculateCommercialPerVisitPSSF(inputs);
  const visits = COMMERCIAL_VISITS_PER_YEAR[inputs.tier] || 1;

  return ((perVisitPSSF * visits) / 12) * rate;
}

Commercial tier frequency:
- Annual Shield = 1 visit/year
- Bi-Annual Shield = 2 visits/year
- Quarterly Guard = 4 visits/year

Do NOT use condition logic.
Do NOT use total building square footage.

9. MULTIFAMILY PRICING LOGIC
==================================================

Multifamily must keep its unique model.

Step 1:
Unit turns are already monthly and must NOT be multiplied by tier frequency.

Step 2:
Common areas are tier-frequency based and must be multiplied by the selected tier cadence.

Use this model:

common area PSSF per visit
× visits per year
÷ 12
× base rate
× applicable efficiency factor

Implement or verify this logic:

function calculateCommonAreaPerVisitPSSF(areas) {
  let total = 0;

  if (!areas || areas.length === 0) return 0;

  areas.forEach(area => {
    const qty = area.quantity || 0;
    const floors = area.floors || 1;
    const sqft = area.squareFeet || 0;
    const service = area.service || "touchup";

    const serviceMultiplier = SERVICE_MULTIPLIERS[service] || 0.35;

    if (qty > 0 && sqft > 0) {
      total += qty * floors * sqft * 3.5 * serviceMultiplier;
    }
  });

  return total;
}

function calculateMultifamilyCommonAreasMonthly(areas, tier, rate) {
  if (tier === "essential") return 0;

  const perVisitPSSF = calculateCommonAreaPerVisitPSSF(areas);
  const visits = MULTIFAMILY_VISITS_PER_YEAR[tier] || 0;

  return ((perVisitPSSF * visits) / 12) * rate;
}

Do NOT multiply unit turns by tier frequency.
Only common areas use tier visit frequency.
